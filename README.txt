ROUANE — Luxury Website
=======================

Files:
- index.html: website structure
- style.css: styling and responsive layout
- script.js: mobile navigation and reveal animations
- assets/logo.png: logo with transparent background

How to use:
1. Extract the ZIP.
2. Keep index.html, style.css, script.js, and assets/ together in the same folder.
3. Open index.html in your browser.
4. To publish on GitHub Pages or Netlify, upload the complete folder contents.

Notes:
- Product imagery is intentionally blurred, as requested.
- Google Fonts and remote Unsplash photos require an internet connection.
